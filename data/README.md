# Data

Dataset storage for raw, processed, and BI-ready exports.

## Structure
```
data/
├── raw/        # Source CSVs (cards, devices, merchants, rules, transactions)
├── processed/  # Intermediate tables (optional)
└── bi/         # Aggregated exports for Power BI
```

## Notes
- Raw files are generated by `src/generate_raw_data.py`.
- BI exports are produced by `src/export_bi_data.py`.
